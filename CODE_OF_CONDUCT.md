# FXOTP Code of Conduct

## Our Commitment

The FXVN Open Trading Protocol (FXOTP) community is committed to providing
a respectful, constructive, and welcoming environment for everyone who
participates in the project.

We welcome developers, traders, researchers, documentation contributors,
platform builders, testers, and other community members.

## Expected Behavior

Participants are expected to:

- Communicate respectfully and constructively
- Welcome different levels of technical experience
- Focus discussions on ideas, code, specifications, and technical issues
- Provide useful and actionable feedback
- Respect differing technical opinions
- Accept constructive criticism
- Help maintain a collaborative open-source environment
- Respect the privacy and security of other participants

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment or personal attacks
- Discriminatory or insulting language
- Threats or intimidation
- Deliberate disruption of technical discussions
- Publishing another person's private information without permission
- Posting credentials, private keys, recovery phrases, passwords, or other
  sensitive information
- Spam or unrelated commercial promotion
- Attempts to manipulate the project for undisclosed commercial interests

## Technical Discussions

Disagreement about protocol design is normal and welcome.

Technical decisions should be discussed based on factors such as:

- Interoperability
- Security
- Simplicity
- Compatibility
- Maintainability
- Platform independence
- Practical implementation experience

Participants should criticize ideas and implementations rather than individuals.

## Commercial Interests

Commercial companies and projects are welcome to participate in FXOTP.

However, sponsorship, commercial relationships, or financial contributions
do not provide special control over protocol decisions.

Participants representing a commercial interest should disclose that
relationship when it is relevant to a technical proposal or discussion.

## Enforcement

Project maintainers are responsible for interpreting and enforcing this
Code of Conduct.

Maintainers may edit, remove, or reject comments, commits, issues,
pull requests, discussions, or other contributions that violate these
standards.

Serious or repeated violations may result in temporary or permanent
restrictions from participating in project spaces.

## Reporting

If you experience or observe unacceptable behavior, please contact the
project maintainers privately.

Do not use public GitHub Issues to report matters involving sensitive
personal or security information.

## Scope

This Code of Conduct applies to official FXOTP project spaces, including:

- GitHub Issues
- GitHub Discussions
- Pull Requests
- Code reviews
- Documentation contributions
- Other official FXOTP community spaces

## Project Goal

FXOTP exists to improve interoperability between trading applications
through an open, secure, and platform-independent protocol.

Community participation should support that goal while maintaining a
professional and constructive environment.
